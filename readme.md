# Простой веб-сервер на встроенном Python

Минималистичный локальный веб-сервер, написанный на стандартной библиотеке Python (`http.server`). Сервер автоматически отдает главную HTML-страницу и корректно связывает статические файлы (CSS-стили и JavaScript-скрипты) без использования сторонних фреймворков (Flask, Django, FastAPI и др.).

## 📂 Структура проекта

Для корректной работы сервера структура файлов в вашей папке должна выглядеть следующим образом:

```text
название_проекта/
│
├── static/                # Папка для статических файлов
│   ├── css/
│   │   └── style.css      # Ваши стили
│   └── js/
│       └── script.js      # Ваши скрипты
│
├── web/                   # Папка для шаблонов страниц
│   └── index.html         # Главная страница (Bootstrap-верстка)
│
├── server.py              # Код сервера (ваш скрипт)
└── .gitignore             # Исключения для Git
```

## 🚀 Как запустить проект

1. Убедитесь, что у вас установлен Python 3.
2. Поместите код сервера в файл `server.py`.
3. Откройте терминал в корневой папке проекта и запустите команду:
   ```bash
   python server.py
   ```
4. Откройте любимый браузер и перейдите по адресу: [http://localhost:8000](http://localhost:8000)

## 🛠️ Как подключать CSS и JS в `index.html`

Поскольку сервер обрабатывает статику через проверку пути `/static/`, в вашем HTML-файле пути к стилям и скриптам должны начинаться со **слеша `/`**:

```html
<!-- Подключение стилей Bootstrap (из CDN) -->
<link href="https://jsdelivr.net" rel="stylesheet">

<!-- Подключение ваших кастомных стилей из папки static -->
<link rel="stylesheet" href="/static/css/style.css">

<!-- Подключение вашего скрипта перед закрывающим тегом </body> -->
<script src="/static/js/script.js"></script>
```

## 📝 Особенности работы сервера

* **Маршрутизация**: На любой запрос (кроме папки `/static/`) сервер всегда возвращает файл `web/index.html`. Это удобно, если вы захотите реализовать Single Page Application (SPA).
* **MIME-типы**: Сервер автоматически проставляет `Content-type` (`text/css` или `application/javascript`), благодаря чему браузер без ошибок применяет ваши стили и выполняет скрипты.
* **Сторонние библиотеки**: Не требуются. Используются только встроенные модули Python `http.server` и `os`.
